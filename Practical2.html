About Us

The Department Of Computer Engineering offers quality education in programming, algorithms and modern technology. Our aim is to help students build strong technical and problem-solving skills through hands-on learning and dedicated mentorship.

Academic Programs

B.Tech

Four-year undergraduate programme in Computer Engineering focusing on programming, AI, web technologies and software development.

M.Tech

Two-year postgraduate programme with specialization in advanced Computer Science and Engineering domains.

Ph.D.

Research-based doctoral programme in Artificial Intelligence, Machine Learning, Data Science, Cyber Security and more.

Laboratories

Software Development Lab

Equipped with modern IDEs, compilers and software tools for application development.

Networking Lab

Hands-on experience with routing, switching, network security and server administration.

Artificial Intelligence Lab

Dedicated laboratory for AI, Machine Learning, Deep Learning and Data Analytics.

Web Technologies Lab

Practical training in HTML, CSS, JavaScript, PHP and modern web application development.

Career Opportunities
